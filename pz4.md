### **Шаг 8. Обработка исключений**

Необходимо обеспечить устойчивую работу программы при возникновении ошибок.

Реализовать обработку следующих ситуаций:

1. `FileNotFoundError` — попытка чтения отсутствующего файла.
2. `PermissionError` — отсутствие необходимых прав доступа.
3. `UnicodeDecodeError` — невозможность декодирования содержимого файла как UTF-8.
4. `IsADirectoryError` — попытка открыть каталог как обычный файл.
5. `OSError` — другие ошибки файловой системы, в том числе ошибки копирования и записи.
6. `ValueError` — некорректное значение при преобразовании пользовательских данных, если такое преобразование используется.

Необходимо:

1. Использовать `try-except` при выполнении операций чтения, записи и копирования.
2. Для разных типов исключений предусмотреть понятные сообщения.
3. Использовать блок `else` для действий, выполняемых только после успешного завершения защищённой операции.
4. Использовать `finally` там, где необходимы завершающие действия независимо от результата.
5. Создать функцию `log_error()` для записи ошибок в `logs/errors.log`.
6. Сохранять в журнале дату, время, тип ошибки и её описание.
7. Не допускать неожиданного завершения всей программы при ошибке чтения одного файла.
8. Различать успешное завершение операции и частичное выполнение с ошибками.

Пример содержимого журнала:

```
[2026-11-19 12:00:00] FileNotFoundError: Файл не найден
[2026-11-19 12:00:05] PermissionError: Отказано в доступе
[2026-11-19 12:00:10] UnicodeDecodeError: Ошибка кодировки файла
```

При обработке исключений не рекомендуется использовать пустые блоки `except` или подавлять ошибки без регистрации причины.

**Ожидаемый результат:** Программа корректно реагирует на распространённые ошибки файловой системы, сохраняет диагностические сообщения и продолжает выполнение остальных независимых операций.

### **1. Переменные и типы данных**

В Python переменные создаются при присваивании значения.

```
project_name = "Python Admin Tool"version = "1.0"total_files = 0has_errors = Falsefile_list = []file_statistics = {}
```

Основные типы данных:

| Тип     | Назначение                           |
| ------- | ------------------------------------ |
| `str`   | Текстовые значения                   |
| `int`   | Целые числа                          |
| `float` | Вещественные числа                   |
| `bool`  | Логические значения                  |
| `list`  | Упорядоченная изменяемая коллекция   |
| `tuple` | Упорядоченная неизменяемая коллекция |
| `dict`  | Коллекция пар «ключ — значение»      |
| `set`   | Множество уникальных значений        |

Для вывода информации рекомендуется использовать f-строки.

### **2. Условные конструкции**

Пример:

```
error_count = 2warning_count = 1if error_count > 0:    status = "CRITICAL"elif warning_count > 0:    status = "WARNING"else:    status = "OK"
```

Для проверки нескольких условий можно использовать логические операторы `and`, `or`, `not`.

При реализации классификации необходимо учитывать порядок проверок, чтобы ошибки имели более высокий приоритет, чем предупреждения.

### **3. Циклы**

Цикл `for` используется для перебора последовательностей.

```
files = ["app.log", "system.log", "notes.txt"]for filename in files:    print(filename)
```

Цикл `while` выполняется, пока условие истинно.

```
running = Truewhile running:    command = input("Введите команду: ")    if command == "exit":        running = False
```

Для управления выполнением циклов можно использовать `break` и `continue`.

### **4. Работа с файлами и каталогами**

Для операций с путями рекомендуется использовать `pathlib`.

```
from pathlib import Pathsource = Path("data")if source.is_dir():    for path in source.rglob("*"):        if path.is_file():            print(path.name, path.stat().st_size)
```

Полезные методы:

| Метод               | Назначение                    |
| ------------------- | ----------------------------- |
| `Path.exists()`     | Проверка существования пути   |
| `Path.is_file()`    | Проверка обычного файла       |
| `Path.is_dir()`     | Проверка каталога             |
| `Path.iterdir()`    | Перебор содержимого каталога  |
| `Path.rglob()`      | Рекурсивный поиск             |
| `Path.mkdir()`      | Создание каталога             |
| `Path.stat()`       | Получение характеристик файла |
| `Path.read_text()`  | Чтение текстового файла       |
| `Path.write_text()` | Запись текстового файла       |

Для копирования файлов можно использовать `shutil.copy2()`, который также пытается сохранить часть метаданных исходного файла.

### **5. Чтение и запись файлов**

При работе с текстовыми файлами необходимо указывать кодировку.

```
from pathlib import Pathpath = Path("data/notes.txt")with path.open("r", encoding="utf-8") as file:    for line in file:        print(line.strip())
```

Контекстный менеджер `with` обеспечивает закрытие файла после завершения блока, даже если в процессе чтения возникло исключение.

При обработке больших журналов предпочтительнее построчное чтение, поскольку оно не требует загрузки всего файла в оперативную память.

### **6. Обработка исключений**

Общая структура:

```
try:    # Операция, которая может завершиться ошибкой    ...except FileNotFoundError:    # Обработка отсутствующего файла    ...except PermissionError:    # Обработка отказа в доступе    ...else:    # Выполняется, если исключений не возникло    ...finally:    # Завершающие действия    ...
```

При необходимости получить описание исключения можно использовать `except ... as error`.

Не следует заменять обработку конкретных ошибок универсальным `except:`, поскольку это затрудняет диагностику и может скрывать ошибки самой программы.

### **7. Получение текущей даты и времени**

Для добавления временных меток можно использовать:

```
from datetime import datetimecurrent_time = datetime.now()timestamp = current_time.strftime("%Y-%m-%d_%H-%M-%S")print(timestamp)
```

При создании резервных копий рекомендуется проверять отсутствие каталога с таким же именем, чтобы исключить случайную перезапись данных при нескольких запусках в одну секунду.

## **Советы по улучшению работы**

1. **Разделение программы на функции.** Реализовать отдельные функции для поиска файлов, анализа журналов, формирования отчётов, резервного копирования и обработки ошибок. Это упростит тестирование и последующее расширение приложения.
2. **Использование&#x20;**`pathlib`**.** Предпочитать объектную работу с путями вместо ручного объединения строк через `/` или `\`. Такой подход повышает переносимость программы между Linux, Windows и другими операционными системами.
3. **Минимизация дублирования.** Повторяющиеся операции чтения файлов, подсчёта событий и записи результатов следует выносить в отдельные функции.
4. **Корректная обработка исключений.** Обрабатывать ошибки максимально близко к месту их возникновения, не скрывать причину сбоя и сохранять диагностическую информацию.
5. **Проверка входных данных.** Перед выполнением файловых операций убеждаться, что указан корректный путь, объект имеет ожидаемый тип и необходимые ресурсы доступны.
6. **Экономия оперативной памяти.** При работе с большими журналами использовать построчное чтение вместо загрузки всего содержимого в одну строку или список.
7. **Повышение надёжности резервного копирования.** После копирования проверять наличие целевых файлов и соответствие их размеров исходным. В качестве дополнительного улучшения можно сравнивать хеш-суммы.
8. **Формирование структурированных отчётов.** Помимо текстового отчёта можно реализовать экспорт результатов в JSON с помощью стандартного модуля `json`. Такой формат удобен для последующей автоматической обработки.
9. **Автоматизация без участия пользователя.** В качестве дополнительной функции можно реализовать передачу исходного каталога и каталога отчётов через аргументы командной строки, чтобы программу можно было запускать из Bash-скриптов или планировщика `cron`.
10. **Расширение анализа системных журналов.** Можно добавить поиск событий за определённую дату, фильтрацию по уровням критичности, выявление файлов с максимальным количеством ошибок и сравнение результатов нескольких запусков.
